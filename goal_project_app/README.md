# Contributing

Contributions are welcome and will be fully credited.

Please read this guide before submitting issues or pull requests.

## Etiquette

This project is maintained voluntarily. Please be respectful when submitting issues or pull requests.

Maintain high standards of communication and professionalism.

## Viability

When proposing features, consider whether they are useful to other users of the project.

## Procedure

Before creating an issue:

- Try to reproduce the problem
- Check existing issues and pull requests
- Ensure it hasn’t already been fixed or reported

Before submitting a pull request:

- Ensure the feature does not already exist
- Check existing pull requests
- Keep changes focused and minimal

## Requirements

- PHP 
- XAMPP
- Text Editer
## Pull Requests

We appreciate small, focused pull requests over large changes.
